Privacy Policy

Stream Agent · Last updated: 30 September 2026

Summary

Stream Agent is a desktop app that runs entirely on the user's own computer. There is no server, no hosted backend, and no analytics. The developer cannot see the user's videos, credentials, or account activity.

What is stored, and where

All data stays on the user's own machine:

  • Video files - clips exported by the user's streaming software, and the processed versions the tool creates.
  • Transcripts - generated locally from the clip's audio to produce captions.
  • Access tokens - OAuth tokens for the platforms the user connects, stored in a local file readable only by that user's account.
  • A local database - filenames, titles, posting choices and upload status, so the tool does not process the same clip twice.
  • Twitch chat logs - if the user turns on chat ranking, the public chat of the user's own channel during their streams, used to measure how strongly viewers reacted to each moment.

None of this is transmitted to the developer.

Data shared with third parties

Data leaves the user's computer only for these purposes, and only to the service involved:

  • TikTok - receives each video the user approves, with its caption and the posting choices the user made (who can view it, comments, Duet, Stitch, commercial content disclosure), on the user's own account.
  • YouTube, Facebook, Instagram - the same, where the user has connected those accounts.
  • OpenAI or Anthropic - if the user enables it, the clip's transcript text (and, with chat ranking on, a number describing how active chat was) is sent to pick highlights and draft titles and hashtags. No video and no chat messages are sent.

Each service's own privacy policy governs the data once it is received.

TikTok permissions

The app requests user.info.basic, to show the connected account's display name and avatar so the user can see where a clip will post; video.publish, to post clips the user approves with the settings they chose; and video.upload, to send clips to the user's TikTok drafts instead. It cannot read the user's videos, followers, messages or analytics, and it cannot delete anything.

Retention and deletion

Because everything is local, the user controls retention entirely. Deleting the application folder removes all stored data. Access can be revoked at any time from the relevant platform's app-permissions settings, which immediately invalidates the stored token.

Children

This tool is not directed at children under 13 and is not intended for their use.

Changes

If this policy changes, the updated date above will change with it.
